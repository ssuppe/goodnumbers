fix(ui): Re-introduce placeholder forms and fix CSRF for agreements and setup pages

This commit addresses the missing placeholder web forms on the agreements and setup-account pages, which were inadvertently removed during a previous refactoring phase. It also implements the necessary client-side logic to correctly handle CSRF tokens for these forms.

Key changes include:
- Re-introduced the inline HTML forms for `/agreements` and ` /setup-account` in `src/index.ts` to enable basic manual testing.
- Modified `public/js/agreements.js` to fetch the CSRF token from `/api/csrf-token` and include it in the `PUT /api/user/settings` request body when signing agreements.
- Modified `public/js/setup-account.js` to fetch the CSRF token from `/api/csrf-token` and include it in the `PUT /api/user/settings` request body when saving account settings.
- Improved client-side error reporting for both agreements and setup-account pages.

This ensures that the manager can continue to perform manual testing of the onboarding flow.
