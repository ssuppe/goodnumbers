# Security Policy

## Supported Versions

Currently, we only provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of GoodNumbers seriously. If you believe you have found a security vulnerability, please report it to us privately. **Do not open a public GitHub issue for security vulnerabilities.**

Please send an email to **security@goodnumbers.io** with the following information:

- A descriptive title for the vulnerability.
- A detailed description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the vulnerability.
- (Optional) Any proposed fixes or mitigations.

### What to Expect

- We will acknowledge receipt of your report within 48 hours.
- We will provide an estimate for how long it will take to address the issue.
- Once the issue is resolved, we will notify you and credit you for the discovery (if desired).

## Our Commitment

We are committed to resolving security issues in a timely manner. Thank you for helping keep the GoodNumbers community safe!
