Team Update: AGP Component Consolidation & RedesignOverview

We are streamlining the "This Week's Journal" page to reduce cognitive load and visual clutter. The primary change involves removing the standalone ScorecardRow and integrating those metrics directly into a unified Insights Ledger located within the AGP Chart card.Key UX ChangesDe-cluttering: The horizontal ScoreCard row previously sitting above the AGP chart has been removed.Contextual Narrative: Each high-level metric is now paired directly with its AI-driven insight. This allows the user to see the "What" (the data) and the "Why" (the observation) in a single horizontal scan.The "Analysis Card" Pattern: We have moved to a single container for all AGP-related data, reinforcing the relationship between the visual chart and the statistical summaries.UX Specification: The Insights LedgerLayout: A vertical stack of horizontal rows using a 2-column grid (160px for metrics, 1fr for narrative).Typography: \* Labels: 10px font size, Black (900) weight, uppercase with 0.1em letter spacing for an "instrument panel" feel.Values: 20px (text-xl) font size, bold, with high-contrast text.Iconography: Organic emojis with transparent backgrounds and drop shadows to maintain the "Health Journal" aesthetic.Ordering Logic (Mandatory):Avg Glucose (🧭) - The primary directional indicator.Stability (🌊) - The measure of glycemic variance.Time In Range (TIR) (⛵) - Success against standard targets.Time In Tight Range (TITR) (🏝️) - Precision tracking (The "Ideal Island").GMI (Est. A1c) (📈) - Long-term trajectory prediction.Engineering ReferenceThe implementation uses a UnifiedInsightRow component to ensure consistency across the stack.Data Structure Example:{
